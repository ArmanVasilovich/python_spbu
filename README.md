# Python, Data Analysis & Machine Learning

**Coursework, practical assignments, and experiments from my studies at Saint Petersburg State University.**

This repository documents my learning journey from Python fundamentals and working with tables to machine learning, text analysis, and neural networks.

It brings together course materials, my solutions, and exam assignments, showing the topics I have explored, the tools I have used, and my progression toward more complex tasks.

## 🧭 What You’ll Find Here

| Area | Topics |
|---|---|
| **Python & Data Processing** | Programming fundamentals, working with tables, handling missing values, and preparing data for analysis |
| **Exploratory Analysis & Visualization** | Exploring distributions, comparing groups, and presenting findings through charts |
| **Machine Learning** | Classification, regression, algorithm comparison, and prediction quality assessment |
| **Text Analysis** | Sentiment classification of Russian-language messages and analysis of model errors |
| **Neural Networks** | Image classification and adapting pretrained language models to specific tasks |
